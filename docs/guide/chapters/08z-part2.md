# Part II – Build it step by step {.part}

Fifteen steps, from an empty repository to a demo-ready platform. Each step follows the same loop: understand the mechanism, do it by hand, build it in Go, prove it with a "done when" check, and answer the learning checkpoint before you move on. Three go/no-go gates (G1, G2, G3) protect you from building on something that does not work.
